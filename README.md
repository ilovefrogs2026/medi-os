# MEDI✚OS — מוקד רפואי רטרו, מולטי-שחקנים בזמן אמת

משחק דפדפן מרובה משתתפים בסגנון מחשב CRT ישן: מארח יוצר חדר, שחקנים מצטרפים בקוד/QR, וכולם עונים לשיחות חירום, פוגשים דמויות נדירות ומתחרים על הקופה.

## הרצה

אין תלויות — רק Node.js 18 ומעלה.

```bash
node server.js            # http://localhost:3000
PORT=8080 node server.js  # פורט אחר
npm test                  # בדיקת פרוטוקול אוטומטית (כ-50 בדיקות)
```

**משחק עם טלפונים באותה רשת:** השרת מדפיס כתובת `Network: http://192.168.x.x:3000`. כשהמארח פותח מ-localhost, הברקוד מצביע אוטומטית על כתובת הרשת, כך שטלפונים סורקים ומצטרפים ישר.

**בינה מלאכותית אמיתית (אופציונלי):** בלי מפתח, בוט מובנה עונה בערוצי "עזרה" ו"לוחות-מובילים". עם מפתח, התשובות מגיעות מ-Claude:

```bash
ANTHROPIC_API_KEY=sk-ant-... node server.js
# AI_MODEL=claude-haiku-5-5 (ברירת מחדל)
```

**פריסה לאינטרנט:** כל שירות Node שתומך ב-WebSockets (Render, Railway, Fly.io, VPS). פקודת הפעלה: `node server.js`, והשרת מכבד את משתנה הסביבה `PORT`.

## מה יש במשחק

| אזור | פירוט |
|---|---|
| לובי | יצירת קבוצה עם 5/8/12/15 דקות או זמן מותאם, קוד חדר בן 6 ספרות + QR, רשימת שחקנים חיה. המארח יכול להוציא, לדווח על שם (השחקן חייב לבחור שם חדש), למנות מנהלים ולהתחיל. |
| מד"א | 11 פרוטוקולי עזרה ראשונה תמציתיים (החייאה, דימום, חנק, כוויות, שבץ, אלרגיה, סוכר נמוך, שבר, מכת חום, התעלפות, פרכוס). |
| שיחות | 10 מתקשרים רגילים (נפוץ→אגדי, יחד 68%), אבא נמלה 12%, אמא לוויתן 10%, ג'ורג' המסתורי 10% (30 שניות דיבור → כן/לא → שיגור לכוכב ג'ורג': דוד צבי 40%, אח סטרוברי אלפנט 35%, ג'ורג' האגדי 25%). אינדקס דמויות עם פרופילים. |
| DisChat | ערוץ עזרה (בוט AI מצהיר שהוא AI, פנייה לתור המנהלים עם תקציר, תשובת ה-AI והנחיית טיפול; מנהל מצטרף/יוצא/סוגר), ערוץ לוחות-מובילים (רק AI, הודעות מוכנות או חופשיות), צ'אט גלובלי. מנהלים משתיקים ומוציאים. |
| הגדרות | אפקטים ומוזיקה (סינתיסייזר מובנה) עם עוצמה, עברית/אנגלית (RTL/LTR), כיבוי אפקט CRT. |

השרת הוא מקור האמת: ההגרלות, הכסף, הטיימר והרשאות נקבעים בשרת (התשובה הנכונה לא נשלחת ללקוח). רענון דף מחבר מחדש את השחקן לאותו מצב.

## מבנה

```
server.js            שרת HTTP + לוגיקת משחק
server/ws.js         שכבת WebSocket (ללא תלויות)
server/ai.js         בוטי עזרה ולוחות מובילים (מובנה / Claude)
server/qr.js         יצירת QR כ-SVG (מקודד MIT מצורף ב-server/vendor)
shared/content.js    דמויות, סיכויים, פרוטוקולים — משותף לשרת וללקוח
public/              ממשק: index.html, style.css, app.js, i18n.js, audio.js, net.js
test/                בדיקת פרוטוקול + בדיקת דפדפן (Playwright)
```

---

**English:** Zero-dependency Node 18+ app. `node server.js`, open `http://localhost:3000`, create a group, share the code/QR. Set `ANTHROPIC_API_KEY` for Claude-powered help/leaderboard bots; otherwise a built-in assistant answers. Deploy to any Node host with WebSocket support.
